# 감정단어 (MoodWords) — Wear OS

워치로 심박을 재고 몇 가지를 물어본 뒤, 지금 감정을 **단어와 뜻**으로 알려주고 기록하는 앱입니다. 워치 단독으로 동작하며 기록은 워치 안에만 저장됩니다.

## 흐름
1. **심박 측정 (15초)** — Health Services로 측정, 뒤쪽 절반 평균 사용
2. **에너지 확인** — 평소 안정 심박과 비교해 높음/보통/낮음을 추정해 보여주고, 사용자가 확인하거나 고침
3. **기분 방향 질문** — 좋은 쪽 / 그저 그럼 / 안 좋은 쪽 (심박만으로는 구분 불가한 부분)
4. **결과** — 에너지 × 기분 3×3 표에서 대표 단어 + 뜻, 다른 후보 단어로 바꿀 수 있음
5. **기록** — 시간, 단어, 심박 저장 (최근 200개)

평소 안정 심박은 70bpm에서 시작해, 사용자가 "에너지 낮음"으로 확인한 측정값으로 조금씩 개인에게 맞춰집니다.

## 파일
- `EmotionWords.kt` — 감정 단어 27개와 뜻, 에너지 추정 규칙
- `HeartRate.kt` — 심박 센서 연결
- `MoodStore.kt` — 기록 / 안정 심박 저장
- `MainActivity.kt` — 화면 6개 (홈, 측정, 질문 2개, 결과, 기록)

## 실행
1. Android Studio에서 `moodwords` 폴더 열기
2. Wear OS 에뮬레이터(API 30+) 실행 → 확장 컨트롤의 Health Services 메뉴에서 가짜 심박 데이터를 켤 수 있음
3. 실제 갤럭시워치: 개발자 모드 → Wi‑Fi 디버깅 → `adb pair` / `adb connect` 후 Run

## 참고
심박은 감정의 "강도/긴장"만 알려줄 뿐 감정 자체를 판별하지는 못합니다. 그래서 추정값은 제안일 뿐이고 최종 선택은 사용자가 합니다. 의료용 앱이 아닙니다.
